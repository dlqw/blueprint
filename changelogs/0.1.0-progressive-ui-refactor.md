# 0.1.0 Progressive UI Refactor

- Added a local React UI primitive layer for dialog backdrops, dialog frames, search fields, list action buttons, and keyboard shortcut badges.
- Added local menu surface, menu section, and menu action primitives for compact command menus.
- Added local tabs list and tabs trigger primitives for compact settings-style tab groups.
- Added local segmented control and segmented button primitives for compact option sets.
- Added a local checkbox row primitive for settings-style toggle rows.
- Added local text input, number input, checkbox input, color input, and select input primitives for workbench form fields.
- Added compact base styling for shared input primitives, including focus and disabled states.
- Added a local command button primitive for compact footer and toolbar text commands.
- Added a local panel header primitive for docked workbench panel chrome.
- Migrated the command palette, node find dialog, Blueprint sidebar chrome/tabs/searches/list actions/bookmark and breakpoint fields, contextual selection toolbox, canvas edge context menus, loading retry action, node creation overlay chrome/filter/favorite actions/search field, node creation candidate pick rows, main toolbar icon buttons, toolbar overflow menu, template registry shell/actions/selection rows, editor settings shell, editor settings tabs, editor settings segmented controls, checkbox rows, shortcut reset actions and shortcut fields, footer actions, inspector dock chrome, inspector linked-port unlink actions, inspector linked/type fields, inspector boolean/value fields, inspector issue focus rows, comment inspector fields and custom color input, collapsed dock buttons, bottom run panel toggle, floating run action bar buttons, run console toolbar actions, run console row copy actions, runtime console row selection actions, runtime history item tools, runtime error summary actions, trace stepper controls, runtime comparison item inspect/copy actions, runtime details trace rows, and runtime details filter/sort/copy controls to compose those primitives while keeping the existing Blueprint canvas and node editor engine unchanged.
- Refreshed the existing Blueprint node visual layer with richer accent-aware shells, headers, runtime badges, breakpoint markers, execution/data row surfaces, and port pins without changing node dimensions, port hit targets, graph data, or the current canvas engine.
- Added minimap parity for selected, disabled, breakpoint, and runtime node states using existing graph/runtime state without changing minimap projection or viewport behavior.
- Added Playwright layout coverage that verifies selected, disabled, breakpoint, runtime-error, and minimap state affordances stay visible across built-in themes.
- Added UI refactor boundary tests that scan non-primitive webview TSX, keep raw buttons limited to specialized App canvas pointer targets, keep raw form controls isolated to primitive internals, keep canvas/graph core modules independent from workbench UI primitives, and keep candidate graph-engine dependencies out of package manifests and non-test shipped source.
- Added a typed shared graph-engine spike fixture so FlowGram, litegraph.js, and React Flow evaluations use the same representative BlueprintGraph without schema changes.
- Added a graph-engine spike report template with acceptance gates, rejection gates, dependency notes, manual checklist, artifact fields, and recommendation format.
- Added graph-engine spike documentation consistency tests to keep the plan and report template aligned.
- Added a workbench UI primitive architecture guide and boundary-test coverage for future contribution rules, canvas exceptions, CSS-token styling direction, and graph-engine dependency guardrails.
- Added ref forwarding and safe default `type="button"` behavior to shared button primitives while preserving explicit button type overrides.
- Added ref forwarding to shared structural primitives for dialogs, headers, menus, tabs, segmented controls, and checkbox rows.
- Added `IconButton` accessible-label fallback from string titles while preserving explicit `aria-label` overrides.
- Added `data-state="active|inactive"` attributes to active-aware shared primitives while preserving existing active classes.
- Added `data-disabled` markers to disabled-capable shared primitives while preserving native disabled behavior.
- Added base CSS selector support and boundary coverage for primitive `data-state` and `data-disabled` attributes.
- Added a progressive UI refactor completion audit mapping the goal to evidence, verification commands, and the no-graph-engine-replacement decision.
- Added primitive style contract coverage so exported `ui-*` primitive classes must have corresponding CSS selectors.
- Added direct tests for UI primitive roles, dismissal behavior, active states, and action callbacks.
- Added a graph engine spike plan for future FlowGram, litegraph.js, and React Flow evaluations without adding candidate dependencies to this UI refactor.
- Kept this phase scoped to non-canvas workbench UI so future FlowGram, litegraph.js, or React Flow evaluations can remain isolated spikes.
